New here? How to use this dashboard · 1 minute
  1. Read the headlineThe big number is the total value of Indonesian stocks held by the 10 tracked fund managers, with the change from the previous quarter.
  2. Pick a quarterClick any quarter in the Period grid, click a point on the hero chart, or use the ← → keys. Every number on the page updates.
  3. Filter managersToggle managers on or off in the Managers panel. "US funds only" hides Norway's wealth fund.
  4. Drill into a managerClick a manager in "Exposure by manager" to see every Indonesian stock it holds and what changed since last quarter.
  5. Check the money flow"Net flow over a period" shows how much the funds actually bought or sold between two quarters, with price moves stripped out.
  6. Read the evidence"Do foreign fund flows predict the market?" tests whether this buying and selling has predicted IHSG. So far it hasn't. Use it as context, not a trading signal.
